## Description:

so that employees can post short ideas (messages), and other employees 
can like (and remove a like from) that idea. In this release, we implemented all
what we designed in the design sprint (such as the ERD, mock drawing, etc.)

## Instructions on building and running locally on Dokku:
- Set up a remote Git repository.
- Add a remote for Dokku in your project folder:
    <git remote add dokku dokku@localhost:appname>
- Build and deploy locally with Procfile.
- Push your code to Dokku:
    <git push dokku main>
